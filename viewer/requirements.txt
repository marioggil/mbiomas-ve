# Viewer service runtime dependencies — exact freeze of the working .venv.
#
# Regenerate with:
#   uv pip freeze --python .venv/bin/python | sort
#
# rasterio is REQUIRED, not optional. The clip endpoint imports it lazily to read
# the drawn window from the COG, so without it the service starts and serves the
# map, the legend and the composition panel normally, and then fails on the first
# rectangle a user draws. It was missing from this file while the installed venv
# happened to have it, which is exactly the kind of gap that only surfaces on a
# clean environment or in a fresh image.
#
# rasterio's manylinux wheels bundle their own GDAL, so the image needs no system
# GDAL packages. The COG extent for /api/meta is still parsed from the BigTIFF
# header by hand, which keeps GDAL off the import path and startup fast.
#
# httpx and httpcore are test tooling rather than runtime imports; they are kept
# here so that a clean install reproduces this environment exactly.
